怪狗唱片 · 每日提醒工具包

需要电脑上装有 Node.js 18 或更新版本。

1. 把整个文件夹放在任意位置。
2. config.env 里已经填好网站地址和管理口令，别把它发给别人。
3. 把 HARNESS.md 的内容交给你的 DeepSeek 当工作说明，让它每天在这个文件夹里运行
   node pending.mjs --quiet
   有输出就转告你。
4. 你自己想看的时候，直接运行  node pending.mjs
   待做的歌会存在这个文件夹里的「待做的歌」里。
5. （可选）另开一个终端运行  node auto-upload.mjs
   之后把做好的 mp3 按文件里写的名字存进「下载」文件夹，它会自动传上去，不用手动拖。
